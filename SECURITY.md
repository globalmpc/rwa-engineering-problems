# Security Policy

This repository holds problem descriptions and no code, so it has no vulnerabilities of its own.

For a vulnerability in one of the packages listed in the README, **do not open an issue here**. Report it privately through **Security, Report a vulnerability** on that package's repository:

- npm packages: github.com/globalmpc/rwa-kit-js
- Flutter packages: github.com/globalmpc/rwa-kit-flutter

or by email to mpc@globalmpc.tech. Please keep details private until a fix is released.
