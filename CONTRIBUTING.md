# Contributing

This repository holds problems, not code. There are two ways to contribute, and both are issues.

## Add a problem

Open an issue with the **Engineering problem** form. It asks for four things:

1. **Chain and setup.** Which chain, which node provider, which framework or wallet stack.
2. **The problem.** What you did, what happened, what you expected. Symptoms, not conclusions.
3. **Why it matters for RWA.** Who is blocked by it: an issuer, a holder, an auditor, a reviewer.
4. **What would close it.** Optional. A library, a tool, a rule set; or leave it to the discussion.

What we look for: an engineering problem met while building on BNB Chain or another EVM chain, described so that another team can recognise it. Product ideas, token topics and vendor comparisons are out of scope and will be closed with a note.

## Confirm a problem

Comment on an existing issue with your case: the chain, the setup, what you tried. That is the signal we build on. A problem with confirmations from outside this team is the next candidate for a package.

## How a problem is closed

A problem is closed by a released package that solves it. The closing comment names the package and its version. If the package does not cover your case, comment and the issue is reopened.

## Changes to this repository

The README and the issue form change through pull requests. Keep the status table in step with the issues.

## Rules for everything posted here

- No credentials, private keys or wallet addresses, in issues, comments or files.
- No company-internal references. Issues and comments are published text.
- Be specific and short. A problem that fits on one screen is read; one that does not is skipped.
